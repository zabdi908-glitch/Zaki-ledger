## Before you send (do this once)
1. ⚠️ **Buy the domain + set up the mailbox first.** `zachi@zakiledger.co.uk` isn't live yet — these
   are ready for the moment it is. Sending from a half-set-up domain hurts deliverability.
2. Set **SPF + DKIM + DMARC** (DMARC at `p=none` to start). This is what keeps you out of spam.
3. Send from a **human inbox** as `Zaki · Zaki Ledger`, ideally spaced out over a few hours, not all at 09:00.
4. **Log replies** in the tracker in `prospects.md`. Reply rate is the signal.
